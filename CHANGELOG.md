# Changelog

## [0.2.0]

### Features

- Search library photos by text and by criteria (camera, lens, date taken, file format, folder).
- Rate photos and mark them as favorites.
- Filter and sort by rating or favorite.
- Additional keyboard shortcuts (browsing, search, filters, ratings, favorites, and
  sorting).

### Improved

- Preserve the Grid scroll position when returning from Preview mode.

## [0.1.0]

### Added

- Initial desktop application
- Filesystem browsing, thumbnails, and previews
  for CR2, CR3, NEF, RAF, DNG, JPEG, and PNG images.
- Basic library support for importing folders and navigating a library.
