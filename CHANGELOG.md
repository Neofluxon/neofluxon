# Changelog

Notable changes to Neofluxon are documented here.

## [0.1.0] - 2026-11-09

### Added

- Initial desktop application for photography workflow management.
- Filesystem browsing, thumbnails, and previews
  for CR2, CR3, NEF, RAF, DNG, JPEG, and PNG images.
- Basic library support for importing folders and navigating a library.
